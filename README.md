# 人生剧本 · Life Script Interactive

一个 Canvas 2D 绘制的四幕线性互动小作品：

1. **原野夜景** — 等一颗流星，点它
2. **高考教室** — 点黑板倒计时，从 100 数到 1
3. **傍晚城市** — 点左下角的自己，再选清洁工 / 办公楼门 / 路边车
4. **结局** — 「恭喜你完成了属于自己的人生剧本。」

技术栈：Vite 5 + React 18 + TypeScript，纯 Canvas 2D 手绘，无图片资源。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开 http://127.0.0.1:5173/ 即可。
